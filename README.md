EduNexus 🎓

Smart Campus Management System

EduNexus is a student-focused campus management platform designed to simplify academic activities and campus services through a single, user-friendly dashboard.

The platform helps students manage their academic information, track assignments and projects, monitor attendance, access syllabus materials, and submit campus complaints.

🚀 Features

- Student Dashboard – View academic information in one place.
- Assignments – Track upcoming assignments and deadlines.
- Projects – Manage academic projects and milestones.
- Attendance – Monitor attendance records and percentages.
- Syllabus – Access course syllabus and study materials.
- Campus Complaints – Submit and track campus-related issues.
- Notifications – Stay updated with academic and campus announcements.
- Quick Actions – Access important features quickly.
- Responsive Interface – Simple and clean user interface.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/BlackHunter100/HACKATHON

2. Open the project

cd EduNexus

3. Run the frontend

Open "index.html" in your browser, or use the Live Server extension in Visual Studio Code.

4. Start the backend

Once the backend files are added, follow the backend installation instructions.

The frontend is configured to connect to:

http://127.0.0.1:8000

🔗 Backend Integration

The frontend is designed to communicate with the backend using REST API endpoints.

The current JavaScript configuration includes:

const API_BASE_URL = "http://127.0.0.1:8000";

Backend integration will support features such as:

- Student authentication
- Assignment management
- Project tracking
- Attendance records
- Complaint management
- Dashboard statistics
